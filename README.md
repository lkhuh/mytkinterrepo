# My Tkinter Projects

A collection of Python files and experiments built with **Tkinter**, Python's standard GUI toolkit.

## What you'll find here

This repository keeps my Tkinter work in one place, including GUI experiments and projects developed while learning desktop application development.

## Running a script

1. Install Python 3.
2. Open a terminal in the folder containing the script.
3. Run the file you want to try:

   ```bash
   python filename.py
   ```

   Replace `filename.py` with the actual script name. Some projects may have their own dependencies or setup steps, so check the relevant files first.

This is a growing collection. Documentation and organization may vary between projects as I continue improving them.
